recursion
Solve a problem using the answer to a smaller copy of the same problem, until it is small enough to answer directly.
Fibonacci numbers
\(F(0) = 0, \quad F(1) = 1\)
\(F(n) = F(n-1) + F(n-2) \qquad \text{for } n \ge 2\)
math
\(F(0) = 0\) \(F(1) = 1\) \(F(n) = F(n-1) + F(n-2)\)
→
python
def fib(n):    if n <= 1:        return n    return fib(n - 1) + fib(n - 2)
return n covers both base cases: 0 → 0 and 1 → 1 The function calls itself, on smaller inputs The code is the definition.  (We assume \(n \ge 0\).)
what happens when we call
Base cases answer immediately: no more calls.
Each fib(2) gets 1 + 0 = 1.  Now: what does fib(3) return?
fib(3) = 1 + 1 = 2
9 calls, one at a time. Calls go down, answers come up.
where do the waiting calls live?
fib(4)n = 4 · just called
fib(4)n = 4 · waiting on fib(3)
fib(3)n = 3 · waiting on fib(2)
fib(2)n = 2 · waiting on fib(1)

fib(4)n = 4 · has 2 · waiting on fib(2)
fib(2)n = 2 · has 1 · waiting on fib(0)
fib(0)base case · returns 0
call stack
Python keeps one frame per unfinished call.
Each frame has its own n, and remembers what it is waiting for.
The stack is the path from the root to the current call.
def countdown(n):    if n == 0:        return    print(n)    countdown(n - 2)

A base case only helps if every call moves toward it.
claim
For every \(n \ge 0\):  \(\texttt{fib}(n) = F(n)\)
base cases
\(\texttt{fib}(0) = 0 = F(0), \quad \texttt{fib}(1) = 1 = F(1)\)
assume
\(\texttt{fib}(k) = F(k)\) for every \(0 \le k < n\)
step \(n \ge 2\)
\(\texttt{fib}(n) = \texttt{fib}(n-1) + \texttt{fib}(n-2)\) \(= F(n-1) + F(n-2)\) \(= F(n)\)
Trusting the smaller call is the induction hypothesis.
What if there were no smallest doll?
You'd open dolls forever.
That's countdown(5).

find the three parts
A list is either empty, or one item followed by a smaller list.
def total(xs):    if xs == []:        return 0    return xs[0] + total(xs[1:])
